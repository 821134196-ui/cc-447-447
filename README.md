# 换热站供暖曲线与报修联动系统

面向社区换热站的运行联动平台：管理换热站、楼栋、供回水温度/压力、循环泵、
室外温度、运行班次、调节指令、居民报修与处置回访。住户信息与仪表数据为模拟内容，
**零第三方依赖**，仅用 Python 3 标准库 + 原生 HTML/SVG/JS。

## 一条命令启动

```bash
python3 run.py
# 或
bash start.sh
```

首次启动自动建库并写入**预置两天数据**（2 个站点、6 栋楼、48 户模拟住户、
约 1.15 万条读数、4 个已交接班次与不可覆盖快照、覆盖指令全生命周期的样例、
报修/回访/七类事件）。随后打开 <http://127.0.0.1:8000/>。

常用参数：`--host 0.0.0.0 --port 8000`、`--reseed`（清空重建预置数据）。
运行数据存于 `data/heating.db`，交接附件存于 `data/handover_attachments/`，
可用环境变量 `HEATING_DB` / `HEATING_DATA` 覆盖。

## 业务规则

### 运行快照（不可覆盖）
每个班次接收测点读数，可随时形成运行快照；交接时自动生成末次快照。快照把当时
窗口内的读数完整复制到 `snapshot_readings` 冻结保存，系统不提供任何修改/删除入口。

### 供暖曲线版本与乐观并发
- 曲线锚点：室外温度 → 供水/回水目标温度，校验单调性、供回水工艺区间与温差范围。
- 每次提交生成新版本（版本链 + `base_version`）。两名值班员同时基于同一版本编辑时，
  **后提交者收到 409 版本冲突提示**，前端可一键"基于最新版本重新编辑"。

### 调节指令生命周期
`待复核 → 待执行 → 生效观察 → 结束`（驳回则为 `已驳回`）。
- 越限（供水 >75℃ 或 <40℃、温差越界、单点调整 >±10℃）指令**必须站长批准**，
  提交时即产生越限提醒，滞留 30 分钟再提醒；运维只能执行、不能批准。
- 生效观察期默认 90 分钟，**自动关联同楼栋同时段冷暖报修**；结束时按关联报修
  判定有效/无效/不确定。观察窗到期产生提醒。

### 七类事件，分开建单、分角色处置
传感器断点（运维，补录后自动关闭）、温差异常（值班员，恢复自动关闭）、
压力骤降（值班员）、水泵切换（运维）、集中不热（值班员，60 分钟内同楼栋 ≥3 件）、
重复报修（客服，同户同类 24h 内自动归并）、回访不满意（客服，工单自动重开）。

### 数据权限
客服与运维接口返回脱敏住户（姓名 `王**`、手机 `130****1234`），房号保留以便定位；
值班员/站长可见完整信息。所有写接口按角色鉴权。

## 界面

冷白底色，**供水红 `#d8392f`、回水蓝 `#2a78d6`**（已通过色盲/对比度校验，
CVD ΔE>25），楼栋叠加比较使用青绿/琥珀/品红/紫分类色并带直接标注；不使用红蓝渐变
铺底。包含：站点总览、曲线编辑（与生效曲线虚线对照）、实时趋势（仅必要刻度、
crosshair 提示、单楼栋供回水/多楼栋供水叠加两种模式、补录点加环标记）、
指令审批（**上下分栏对照旧/新曲线**与逐点温差变化）、报修聚合（**表格微型条形**
展示密度）、班次交接（快照查看、附件上传下载）、回访统计（满意率、分类对比、
不满意重开列表）。

## 后台进程内任务

- 每 15 秒一拍：模拟适配器按物理模型（室外日变化、曲线跟随、一阶惯性）产生读数，
  并随机注入断点/压降/温差异常/水泵切换。
- 每 60 秒：事件检测、读数小时汇总、观察窗报修关联与到期提醒、越限滞留提醒。

## 目录结构

```
run.py / start.sh        一键启动
app/db.py                SQLite schema、连接、不可覆盖快照/版本表
app/auth.py              角色会话与住户脱敏
app/curves.py            曲线校验、版本链、乐观并发、越限判定
app/commands.py          指令生命周期、观察窗报修关联
app/readings.py          读数采集、断点补录、趋势、小时汇总
app/shifts.py            班次、快照冻结、本地附件
app/tickets.py           报修归并、集中不热、回访重开
app/monitor.py           七类事件检测与分角色处置
app/simulator.py         仪表模拟适配器
app/worker.py            进程内后台任务
app/seed.py              两天预置数据
app/server.py            零依赖 HTTP + JSON API
web/                     原生前端（index.html / styles.css / app.js）
```
